# Tool assessments

This directory contains one assessment folder for each selected AI tool category.

## Selected tools

| Category | Tool | Assessment |
|---|---|---|
| Chatbot | ChatGPT | [ChatGPT assessment](chatbot-chatgpt/README.md) |
| AI agent | Zapier Agents | [Zapier Agents assessment](agent-zapier-agents/README.md) |
| Image generation | Adobe Firefly | [Adobe Firefly assessment](image-adobe-firefly/README.md) |
| Video generation | Runway | [Runway assessment](video-runway/README.md) |

## Status

All four assessments are **not yet conducted**. The folder documents the planned assessment scope and records what must be verified. Do not interpret planned test cases as completed tests or findings.

Use the shared [tool assessment template](../templates/tool-assessment-template.md), [test-case template](../templates/test-case-template.csv), and [risk register template](../templates/risk-register-template.csv).
