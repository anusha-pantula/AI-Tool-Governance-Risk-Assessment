# Zapier Agents: AI agent assessment

**Category:** AI agent / agentic workflow tool  
**Provider:** Zapier  
**Assessment status:** Not assessed  
**Account access status:** Public free access is documented, but the current product transition and exact account experience must be verified.

## Product-status checkpoint

Zapier documentation states that the company is moving Agents to AI by Zapier. Its Free plan documentation describes access to free versions of Zapier Agents and Zapier Chatbots. A separate Agents usage article describes a 400-activity monthly Free allowance and notes that testing counts toward the free activity quota. Zapier's general Free plan separately describes 100 monthly tasks for Zap workflows and MCP server actions.

These are separate product and usage descriptions. Do not combine the allowances. Before testing, record the exact product name visible in the account, current plan, activity/task counters, available actions, and any migration or deprecation notice.

If the selected Agents product is no longer accessible, pause and discuss a replacement rather than silently switching products.

## Assessment focus

Examine agent autonomy, task planning, use of permitted tools, action boundaries, approval points, failure handling, transparency of execution, and human control.

## Planned test themes

1. Understanding and decomposing a simple multi-step task
2. Planning a workflow using only permitted actions
3. Handling an unavailable or failed step
4. Asking for clarification when instructions are ambiguous
5. Requesting approval before a consequential action
6. Respecting a deliberately limited permission scope
7. Reporting completed, failed, and unverified actions accurately
8. Stopping or handing control back when a task exceeds its scope

These are proposed themes, not completed tests.

## Safe testing setup

Use a sandbox or test-only account and synthetic records. Do not connect personal email, work systems, production applications, customer data, or any system containing confidential information. Prefer a harmless test action such as creating a dummy record in a test workspace. If a safe sandbox is unavailable, use a simulated workflow and assess documented controls instead.

## Configuration to record

- Exact product name and interface
- Account plan and date checked
- Activity and task quotas shown
- Connected apps and permissions
- Available approval, pause, and stop controls
- Agent model or version, if disclosed
