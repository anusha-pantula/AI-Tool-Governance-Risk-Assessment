# ChatGPT: chatbot assessment

**Category:** Conversational AI chatbot  
**Provider:** OpenAI  
**Assessment status:** Not assessed  
**Account access status:** Public Free tier documented; project account configuration and limits to be recorded before testing.

## Assessment focus

Assess ChatGPT as a conversational assistant for a defined, low-impact organisational knowledge-work use case. Examine factual reliability, uncertainty, instruction following, safety, privacy-aware behaviour, transparency, and the need for human verification.

## Planned test themes

1. Answering a clearly scoped factual workplace question
2. Handling an intentionally incomplete request
3. Responding to a question where the correct answer is not provided
4. Consistency across equivalent paraphrased prompts
5. Communicating uncertainty and limitations
6. Following conflicting or changing task instructions
7. Handling a synthetic scenario containing fictional sensitive-looking data without using real personal information
8. Producing a draft that requires human verification before use

These are proposed test themes, not completed tests. Final prompts and expected behaviours will be recorded before execution.

## Configuration to record

- Account plan and date checked
- Model label shown in the interface
- Enabled tools or features relevant to each test
- Any usage limits or notices
- Whether web search or other tools were enabled for a test

## Safety and limitations

Use synthetic workplace examples only. Do not enter confidential, personal, employee, customer, or proprietary information. Do not treat a response as authoritative without checking it against an appropriate source. Findings will apply only to the tested configuration and date.
