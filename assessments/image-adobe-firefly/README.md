# Adobe Firefly: image-generation assessment

**Category:** AI image generation  
**Provider:** Adobe  
**Assessment status:** Not assessed  
**Account access status:** Adobe documents limited free daily generations; exact feature and model availability must be verified in the project account.

## Assessment focus

Assess image generation for a defined, low-impact organisational communication use case. Examine prompt adherence, visual fidelity, representation, artefacts, revision controls, provenance/transparency information, and risks of misleading or inappropriate imagery.

## Planned test themes

1. Following a neutral, specific workplace visual brief
2. Including a defined set of visual elements
3. Handling an ambiguous brief
4. Revising an image after targeted feedback
5. Maintaining consistency across a small set of related images
6. Identifying visible artefacts or unintended details
7. Reviewing available content provenance or Content Credentials information
8. Considering misuse scenarios involving misleading synthetic imagery

These are proposed themes, not completed tests. Use fictional scenes and non-identifiable people; do not generate deceptive images of real individuals.

## Configuration to record

- Account plan and date checked
- Exact image-generation feature and model label
- Daily generation allowance shown
- Any restrictions, watermarks, or upgrade prompts
- Output format and relevant generation settings

## Important scope boundary

Only image-generation features of Adobe Firefly belong to this assessment. Firefly video-generation capabilities are outside this category's test scope. Statements about Adobe's training data, commercial use, or Content Credentials must be attributed to provider documentation unless independently verified.
